# UnityHub visual identity

## Logo

The UnityHub mark combines an interlocking **U/H monogram**, a central cross, and a rising sweep. The monogram represents a connected worship team; the cross identifies the Christian worship context; the sweep suggests forward motion and shared purpose.

Primary artwork: `app/src/main/res/drawable/unityhub_mark.xml` (Android vector) and `docs/brand/unityhub-mark.svg` (scalable SVG).

## Color system

| Token | Hex | Use |
|---|---|---|
| Near black | `#07080A` | Brand and aurora backgrounds |
| Crimson | `#C80F32` | Gradient start / primary brand note |
| Coral | `#F0443D` | Gradient transition |
| Warm orange | `#FF9B43` | Secondary gradient note |
| Amber | `#FFD06B` | Gradient highlight |
| Warm white | `#FFF8F0` | Logo contrast and dark-surface text |

The brand gradient runs **crimson → coral → amber**. Do not introduce purple, indigo, or violet into branded gradients.

## Clear space and use

- Keep at least 12% of the mark width clear around the icon when placing it beside text.
- Use the full-color mark on light or dark neutral surfaces; the mark itself carries its near-black rounded-square tile.
- Use the adaptive icon foreground and dark background as separate layers for Android launchers.
- Use the single-color white version for Android monochrome themed icons and status-bar notification glyphs.
- Do not stretch, recolor individual letters, or place the mark over a busy photograph.

## Wordmark

Use **Unity** in the current surface text color and **Hub** in the crimson-to-amber gradient. Recommended descriptor: “PLAN · LEAD · WORSHIP · TOGETHER”.
